# ChessBot

[English](README.md) | [Русский](README_RU.md)

Высокопроизводительный шахматный бот на Go. Работает напрямую с экраном Android (через root-доступ в Termux или через ADB с компьютера), распознает расстановку фигур с помощью компьютерного зрения, рассчитывает сильнейшие ходы в реальном времени и автоматически выполняет нажатия по доске.

Создатель: **ytika**.

---

## Основные возможности

- **Мультиплатформенность**: Работает на Windows, Linux и напрямую на Android-устройствах через Termux (требуются root-права KernelSU или Magisk).
- **Быстрый многопоточный движок**:
  - Алгоритм Alpha-Beta с параллельным корневым поиском на всех доступных ядрах CPU (`GOMAXPROCS`).
  - Лучевой метод проверки атак (`IsSquareAttacked`) без тяжелой генерации ходов при валидации шаха.
  - Поиск тишины (Quiescence Search) с сортировкой ходов по MVV-LVA для устранения эффекта горизонта и исключения случайных зевков.
  - Эвристика ходов-убийц (Killer Moves) для моментального отсечения пустых веток дерева.
  - Шардированная транспозиционная таблица (16 шардов) с защитой `sync.RWMutex`.
- **Веб-интерфейс в реальном времени**:
  - Локальная веб-доска на WebSockets с отображением состояния матча, подсветкой ходов и логами.

## Сборка и запуск

### Требования

- **Go 1.22+** на компьютере для сборки.
- Android-устройство с открытой игрой Duolingo Chess:
  - **Вариант А (Автономно на телефоне)**: Termux с root-правами (KernelSU / Magisk).
  - **Вариант Б (С компьютера через ADB)**: Включенная отладка по USB (USB Debugging).

---

### Сборка релизов

Для компиляции под все платформы используется утилита `act.go`:

```bash
# Сборка под все системы (Windows, Linux, Android)
go run act.go build all

# Сборка только для Android (ARM64 ELF для Termux)
go run act.go build android

# Сборка для Windows (AMD64 EXE со встроенным ADB)
go run act.go build windows

# Сборка для Linux (AMD64 ELF со встроенным Linux ADB)
go run act.go build linux
```

Собранные бинарники будут находиться в директории `Builds/<версия>/<Платформа>/`.

---

### Запуск на телефоне (Android / Termux)

> # ⚠️ ВНИМАНИЕ: ТРЕБУЮТСЯ ROOT-ПРАВА (KernelSU / Magisk / APatch)!
> **Без наличия Root-прав бот работать на телефоне не сможет, так как ему необходим прямой доступ к захвату экрана (`screencap`) и эмуляции нажатий (`input tap`).**

1. Скачай готовый архив для **Android** из папки с релизом (`Builds/<версия>/Android/`).
2. Распакуй его в любую папку внутри **Termux** (например, в `~/Duolingo`).
3. Запусти скрипт `start.sh`:
   ```bash
   ./start.sh
   ```
   Скрипт автоматически выдаст права на исполнение бинарнику и запустит бота с root-доступом (`su`).

---

### Запуск с компьютера (Windows / Linux)

Для работы с компьютера root на телефоне **не требуется**, но необходимо включить отладку по USB.

#### 1. Как включить отладку по USB на телефоне:
1. Открой **Настройки** телефона → **О телефоне** (или *Сведения о ПО*).
2. Нажимай быстро 7 раз по пункту **«Номер сборки»** (Build Number), пока не появится надпись *«Вы стали разработчиком!»*.
3. Вернись в основные настройки → **Система** (или *Расширенные настройки*) → **Для разработчиков**.
4. Включи пункт **«Отладка по USB»** (USB Debugging).
5. *(Для Xiaomi / HyperOS / MIUI обязательно)*: включи также пункт **«Отладка по USB (Настройки безопасности)»**, иначе телефон запретит эмулировать клики.
6. Подключи телефон к ПК через USB-провод. На экране телефона появится всплывающее окно — нажми **«Всегда разрешать с этого компьютера»** и подтверди.

#### 2. Запуск:
1. Скачай и распакуй готовый архив для своей ОС (**Windows** или **Linux**). В архив уже вшит необходимый ADB.
2. Запусти бота:
   ```bash
   # Windows
   .\ChessBot.exe

   # Linux
   ./chessbot
   ```
3. Чтобы смотреть за игрой через браузер в реальном времени, добавь флаг `-WEB`:
   ```bash
   .\ChessBot.exe -WEB
   ```
   Панель доступна по адресу `http://localhost:5873`.

## Параметры конфигурации (`config.jsonc`)

```jsonc
{
  // Пауза между снимками экрана (в миллисекундах)
  "interval_ms": 10,

  // Порт локального веб-интерфейса
  "web_port": 5873,

  // Включать ли веб-сервер автоматически
  "enable_web": false,

  // Смещение доски по вертикали (Y-ratio) для режима с ботом Oscar
  "y_ratio_oscar": 0.355,

  // Смещение доски по вертикали (Y-ratio) для онлайн-режима с людьми
  "y_ratio_people": 0.336,

  // Папка с шаблонами фигур
  "figures_dir": "./Figures",

  // Допустимая погрешность при распознавании силуэта фигуры
  "max_error_threshold": 500.0,

  // Количество одинаковых кадров для подтверждения смены позиции
  "stability_threshold": 2,

  // Автоматически нажимать ходы на телефоне
  "auto_play": true,

  // Автоматически забирать опыт (XP) после победы
  "auto_claim_xp": true,

  // Автоматически начинать следующий матч из меню/лобби
  "auto_start_game": true,

  // Режим противника: "People" (онлайн) или "Oscar" (встроенный бот)
  "game_type": "People"
}
```
